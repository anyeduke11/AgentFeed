## 4. 验收标准

1. `npm test -w server` 全绿，新增用例 ≥10（T2/T3/T7 带出）
2. e2e：并发 convert 第二请求得 429 busy；failed 记录经 retry 闭环转 success；图文页剪藏图片落盘且阅读器离线可渲染
3. `npm run build -w web` 零错误；失败行重试按钮、busy 提示、分类徽标可见
4. 红线自查全过：ensureColumns 幂等加列（无破坏性迁移）；`{ success }` shape；扫描根边界不动；埋点集合扩容 = CLAUDE.md 同步后的显式对齐
5. PRD 变更日志追加 M2 交付行

## 5. 决策记录

- Ruling: 埋点扩集合加 `webclip`（用户拍板，2026-09-24）——替代 M1 的 'other' 兜底，渠道可独立统计 — 代价：files.ts 合法集合与 CLAUDE.md 需同步，漏同步即红线违规
- Ruling: DNS rebinding 留 backlog（用户确认无 LAN 计划）— 代价：若日后开放 LAN 而未回看此条，webclip 成为内网探测面
- Ruling: retry 更新原记录行而非新增 — 代价：丢失「重试次数」轨迹；如需审计可在 M3 加 attempts 列
- Ruling: 失败分类沿用 code 联合 + busy，不拆 timeout/5xx 细分 code — 代价：分类粒度依赖 message 文本；枚举膨胀风险更低
- Ruling: clipped_at 统一 UTC ISO8601 — 代价：与 PRD §6.1 示例字面不一致，以示例加注解决
